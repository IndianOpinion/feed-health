# Security policy

## Reporting a vulnerability

Email **hello@indianopinion.org** with a description, the affected
version, and steps to reproduce. Please do not open a public issue for a
security problem.

We acknowledge reports within 3 working days and aim to ship a fix or a
mitigation within 30 days, sooner for severe issues. We will credit you in
the release notes unless you ask us not to.

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | yes |

## Scope

In scope: the plugin code in this repository, including the admin
screens, the recording actions, the WP-CLI commands and the uninstall
routine. Out of scope: WordPress core, other plugins, and feeds or
servers the plugin observes.
